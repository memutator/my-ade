# Mahas 0.4.1 — 반영 요구사항 점검표

버전: `0.4.1` (`dist/mahas-0.4.1.AppImage`, `dist/mahas_0.4.1_amd64.deb`)

## 에이전트 상태/알림

- [ ] 앱 시작 시 사용자 config 안의 구 `ade-hook` 경로가 `mahas-hook`으로 자동 교체되어 Codex 완료 알림이 다시 도착함  
  비고: codex `config.toml`, claude/devin/zcode settings 대상 — 신규 provider는 Settings에서 Install 필요
- [ ] 턴 완료 후 에이전트 TUI가 출력을 계속 뿌려도 탭의 working 점이 다시 켜지지 않음  
  비고: turn-complete 이후 idle 잠금 — 다음 turn-start 전까지 유지
- [ ] Devin CLI가 rate-limit으로 턴을 죽일 때 `[Error]` 배너가 error로 분류됨 (빨간 점/알림)  
  비고: Devin은 StopFailure 훅이 없어 pty 출력의 배너로 판별
- [ ] 탭 아이콘을 에디터 위로 드래그해도 텍스트가 붙여넣어지지 않음  
  비고: 네이티브 탭 아이콘 드래그가 CodeMirror drop으로 새던 것 차단

## Cline 하네스

- [ ] 터미널의 cline 세션이 에이전트로 감지되어 탭 상태 점/사이드바 에이전트 목록에 표시됨  
  비고: 매니페스트 `cline.bot` 도메인 — 프로바이더 아이콘/모노그램 적용
- [ ] Settings → Agent hooks에 cline이 있고 Install 후 Task 완료/취소 이벤트가 도착함  
  비고: `~/.cline/hooks/<Event>` 파일 방식 — 기존 사용자 파일은 `.mahas-bak`으로 보존 후 파이프 연결
- [ ] 세션 복구 수락 시 `cline --id <sid>`로 resume됨  
  비고: 세션의 원래 cwd로 cd 후 실행
- [ ] usage 위젯에서 cline 선택 가능 — device flow 로그인 후 쿼터 카드 표시  
  비고: WorkOS device auth, micro-credit 단위 잔액 표시

## Usage 위젯 (다계정)

- [ ] provider 헤더 hover 시 나오는 + 버튼으로 계정 추가 가능  
  비고: OAuth 리다이렉트(codex/grok/gemini), 코드 붙여넣기(claude), 디바이스 플로우(copilot/cline), API 키(zcode/opencode/devin), credential 파일 import 전부 지원
- [ ] 등록한 계정이 `provider@계정` 카드로 provider 헤더 아래에 표시되고 각자 폴링됨  
  비고: 계정 라벨은 credential에서 자동 유도 (grok 이메일, codex id_token 등)
- [ ] 같은 로그인으로 해석되는 소스는 카드 하나로 합쳐짐  
  비고: 시스템 credential + 같은 계정으로 등록된 managed 소스 = 1카드
- [ ] 등록 계정 삭제 가능  
  비고: 카드/설정에서 remove account
- [ ] grok/zcode/opencode/devin 쿼터가 각 CLI 자격증명으로 조회됨  
  비고: claude 없이도 multi-harness 대시보드 구성 가능
- [ ] 폴링/리프레시 중 스피너가 돎  
  비고: 추가·삭제·재조회 busy 상태 표시

## Tokens 위젯

- [ ] 리프 + → Widget → tokens로 새 위젯 탭 추가 가능  
  비고: '하네스 합계'(디스크 세션 ledger 합산) + '추적 중 세션' 섹션
- [ ] 하네스별 in/out/cache/think/cost 토큰 합계와 세션 수가 표시됨  
  비고: ledger는 백그라운드 워커가 스캔 — 스캔 중 스피너 표시

## 패인/탭

- [ ] 탭 컨텍스트 메뉴의 '탭 최소화'로 탭이 스트립에서 사라지고 타이틀바 dock chip이 됨  
  비고: 블록은 언마운트되지 않아 터미널/웹/버퍼가 계속 살아있음
- [ ] dock chip 클릭 시 탭이 복원되고 활성화됨 — 최소화된 패인이면 패인도 함께 올라옴  
  비고: detached 윈도우 탭은 해당 창을 포커스
- [ ] 리프의 모든 탭이 최소화되면 '모든 탭이 최소화됨' 빈 화면 표시  
  비고: 탭 순환(cyclePaneTab)도 최소화 탭을 건너뜀
- [ ] 파일/URL 프로그래매틱 오픈이 포커스된 패인이 아니라 같은 종류 블록을 가진 리프에 스택됨  
  비고: docs는 docs끼리, web은 web끼리 — term은 기존처럼 포커스 기준
- [ ] 최소화된 패인이 있는 레이아웃에서 새 패인 추가/복원 시 위치가 깨지지 않음  
  비고: 숨은 리프가 한 단계 아래로 밀리지 않고, 전부 숨은 트리에선 새 패인이 루트 전체 차지
