# ADE 0.2.0 — 반영 요구사항 점검표

버전: `0.2.0` (`dist/ade-0.2.0.AppImage`, `dist/ade_0.2.0_amd64.deb`)

## 패널 · 탭

- [ ] 패널에 타입이 없음 — 한 패널의 탭 스트립에 터미널·파일·브라우저 탭이 섞여 쌓임  
  비고: Alt+T/B/E 또는 탭 스트립의 `+` 메뉴로 원하는 종류를 추가. 아이콘은 활성 탭의 종류를 따라감
- [ ] 새로 여는 것은 화면을 쪼개지 않고 지금 보는 패널에 탭으로 쌓임  
  비고: A | B 배치에서 파일을 열어도 A가 좁아지지 않음 — 포커스된 패널은 절대 암묵적으로 split되지 않음
- [ ] split은 명시적 제스처로만 생김 — Alt+D(오른쪽) / Alt+S(아래) / 패널 `⋯` 메뉴 / 패널 아이콘 드래그→가장자리 드롭  
  비고: 프로그램이 여는 모든 것(파일 트리 클릭, 터미널 링크, 브라우저 URL)은 스태킹
- [ ] Ctrl+Tab / Ctrl+Shift+Tab이 포커스된 패널의 탭을 순환함 (혼합 스택 포함)  
  비고: 터미널→파일→브라우저 순서대로 같은 스트립 안에서 이동
- [ ] 마지막 탭을 닫으면 패널이 닫힘 — 종류 무관하게 동일  
  비고: 기존 동작 유지
- [ ] 최소화(dock 칩) · 플로팅 · detach가 스택 통째로 동작하고 세션/페이지/버퍼가 유지됨  
  비고: 탭 전환해도 비활성 탭은 마운트 유지 — 셸, 웹페이지 상태, 미저장 버퍼 살아있음

## 에디터

- [ ] 파일 탭이 활성일 때 콘텐츠 좌상단에 작은 아이콘이 떠 있고, 호버(~0.35초)로 디렉터리 트리 오버레이가 열림  
  비고: 도킹/플로팅/detach 전부 동일. 오버레이에서 연 파일은 그 패널에 스태킹
- [ ] 트리 단일 클릭은 이탤릭 미리보기 탭, 더블클릭·편집·"Keep Open"은 고정 탭  
  비고: 미리보기는 패널당 슬롯 하나 — 다음 미리보기가 같은 자리를 덮음

## 브라우저

- [ ] 웹 탭이 활성일 때 페이지 상단에 반투명 헤더가 떠 있음 (호버/포커스 시 표시)  
  비고: 뒤로·앞으로·새로고침(로딩 중엔 정지)·북마크 별·주소창
- [ ] 주소창이 URL과 검색어를 구분해 처리함  
  비고: `example.com` → https://, 스킴 있는 URL은 그대로, 나머지는 Google 검색

## 삭제된 기능

- [ ] todo 기능이 사라짐 — Alt+L, 사이드바 섹션, `+` 메뉴 항목 모두 없음  
  비고: 이전 저장 상태의 todo 패널은 복원 시 자동 폐기
- [ ] 이전 버전(0.1.x)의 저장 상태를 그대로 복원함 — 패널 배치·탭·플로팅·최소화 유지  
  비고: 기존 타입 패널이 탭 스택으로 마이그레이션됨 (stateVersion 3)

## 종료

- [ ] 실행 중인 터미널 세션이 있으면 종료 시 확인 모달이 뜸 — "실행 중인 터미널 세션 N개" [취소] [종료]  
  비고: X 버튼·Alt+F4·Cmd+Q 모두 동일하게 가로챔. detached 창의 터미널도 카운트에 포함
- [ ] 실행 중인 터미널이 없으면 모달 없이 바로 종료됨  
  비고: 마찰 없음 — 기존과 동일
