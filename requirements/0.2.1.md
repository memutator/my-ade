# ADE 0.2.1 — 반영 요구사항 점검표

버전: `0.2.1` (`dist/ade-0.2.1.AppImage`, `dist/ade_0.2.1_amd64.deb`)

## 탭 드래그 & 드롭

- [ ] 탭을 꾹 누른 채(~0.2초) 드래그하면 고스트 칩이 커서를 따라다님  
  비고: 패널 아이콘 드래그와 같은 제스처 — 짧게 클릭하면 기존처럼 탭 활성화
- [ ] 같은 탭 스트립 안에서 좌우로 드래그하면 순서가 바뀜 — 삽입 위치에 얇은 세로선이 표시됨  
  비고: 기존 HTML5 reorder를 대체 — 이제 스트립 밖으로도 드래그 가능
- [ ] 다른 패널의 탭 스트립(또는 중앙)에 드롭하면 그 패널에 탭이 쌓이고 활성화됨  
  비고: 터미널·파일·브라우저 탭 모두 동일 — 패널 타입 구분 없음
- [ ] 패널 가장자리에 드롭하면 그 패널이 split되고 탭이 새 절반에 들어감  
  비고: 자기 패널 가장자리에 드롭해도 됨 — 탭 하나만 떼어내는 제스처
- [ ] 워크스페이스 탭(타이틀바)에 드롭하면 그 워크스페이스에 새 패널로 이동 — 호버 ~0.4초로 드래그 중 워크스페이스 전환도 됨  
  비고: 드롭하면 해당 워크스페이스가 활성화되며 탭이 포커스됨
- [ ] 빈 워크스페이스 배경에 드롭해도 새 패널로 들어감  
  비고: 워크스페이스 탭 드롭과 동일한 결과
- [ ] Esc로 드래그 취소 — 아무 변화 없음  
  비고: 창 밖에서 버튼을 놓거나 창이 포커스를 잃어도 취소됨
- [ ] 이동한 터미널 탭은 셸 세션이 그대로 살아있음 — 재시작/재연결 없음  
  비고: pty는 패널이 아니라 탭 레코드에 귀속 — 어디로 옮겨도 유지
- [ ] 드래그로 탭이 다 빠진 패널은 자동으로 닫힘  
  비고: 마지막 탭 닫기와 같은 규칙
- [ ] detached 창에서는 탭 순서 변경만 됨 — 다른 패널/워크스페이스로의 드롭은 없음  
  비고: detached 창은 패널 하나만 보여주므로 reorder만 지원

## 알림

- [ ] 탭을 다른 패널/워크스페이스로 옮겨도 그 안의 에이전트 알림·읽지않음 배지가 탭을 따라감  
  비고: 훅 이벤트는 옛 paneId를 찍지만 탭 id로 다시 찾아 라우팅 — 알림 클릭 시 옮겨진 위치로 점프
