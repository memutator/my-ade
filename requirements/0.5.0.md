# Mahas 0.5.0 — 반영 요구사항 점검표

버전: `0.5.0` (`dist/mahas-0.5.0.AppImage`, `dist/mahas_0.5.0_amd64.deb`)

## 사용량과 통계

- [ ] 사용량 화면을 닫아도 백그라운드 서비스가 기록을 계속 수집한다.  
  비고:
- [ ] 앱을 다시 열거나 원본 세션 파일을 삭제해도 이미 수집된 사용량을 조회할 수 있다.  
  비고:
- [ ] 같은 기록을 다시 수집해도 사용량이 중복으로 더해지지 않으며, 수정된 기록은 기존 합계에 반영된다.  
  비고:
- [ ] 하네스·제공자·모델별 사용량을 구분하고, 귀속을 확인할 수 없는 사용량은 별도로 표시한다.  
  비고:
- [ ] 요청한 모델과 실제 응답한 모델을 구분하며, 모델 이름만 관측된 경우 그 이름을 확인할 수 있다.  
  비고:
- [ ] 전체 사용량은 목록에 보이는 일부 항목의 수와 관계없이 유지되며, 목록이 일부만 조회된 경우 이를 확인할 수 있다.  
  비고:
- [ ] 미확인 사용량을 0과 구분하고, 수집 누락·부분 수집·최종 반영 시점을 확인할 수 있다.  
  비고:
- [ ] 완료된 주의 평균과 날짜별·시간대별 통계를 조회하고, 시간대 및 일광절약시간 경계가 반영된다.  
  비고:
- [ ] 같은 quota pool을 공유한다는 근거가 있는 연결의 하네스별 관측 토큰 지분과 귀속 미확인량을 확인할 수 있다.  
  비고:

## 계정과 quota

- [ ] 제공 서비스에 맞는 로그인·인증 코드·기기 코드·API 키 입력을 사용해 연결을 추가한다.  
  비고:
- [ ] 로그인한 계정이 아직 특정 하네스와 연결되지 않아도 사용량 화면에서 계정을 확인하고 quota 새로고침을 요청할 수 있다.  
  비고:
- [ ] 기존 인증 파일의 연결을 확인하고, 연결을 제거해도 과거 사용 이력은 남는다.  
  비고:
- [ ] 상품을 선택해 인증 파일을 가져오면 실제 계정 연결로 등록되며, 다시 가져와도 중복 계정이 생기지 않는다.  
  비고:
- [ ] 계정을 교체하면 새 계정과 이전 계정의 사용 이력이 구분된다.  
  비고:
- [ ] quota 조회가 실패하면 실패 상태와 마지막 성공 값을 함께 확인할 수 있다.  
  비고:

## 세션과 알림

- [ ] 저장된 세션 목록에서 하네스·부모/자식 관계·재개 가능 여부를 확인한다.  
  비고:
- [ ] 실행 중인 저장 세션에서 해당 탭으로 이동하며, 서로 다른 세션의 이름이나 ID가 비슷해도 잘못된 탭으로 이동하지 않는다.  
  비고:
- [ ] 기존 창과 탭에 연결된 재개 대상이 앱 재시작 후에도 올바른 디렉터리에서 열린다.  
  비고:
- [ ] 완료·입력 요청·오류 알림이 저장된 이벤트를 기준으로 전달되고, 자식 및 외부 세션은 사용자 알림을 만들지 않는다.  
  비고:

## 작업 화면과 서비스

- [ ] 여러 프로젝트·창·백그라운드 위젯을 전환해도 Workbench의 선택과 대기 작업이 서로 섞이지 않는다.  
  비고:
- [ ] Workbench의 계획·담당·팀·검사 화면이 서비스의 현재 상태와 일치한다.  
  비고:
- [ ] 탭 이동·분할·최소화·분리 창 전환 중 터미널·웹 페이지·미저장 파일이 유지된다.  
  비고:
- [ ] 새 설치와 기존 데이터 업그레이드 모두에서 필요한 서비스가 시작되고, 연결 실패는 화면에서 확인할 수 있다.  
  비고:
- [ ] 통합 Pack의 등록·검사 상태를 확인하고, 특정 통합이 실패해도 다른 통합의 저장된 정보를 조회할 수 있다.  
  비고:
