# ADE 0.1.1 — 반영 요구사항 점검표

버전: `0.1.1` (`dist/ade-0.1.1.AppImage`, `dist/ade_0.1.1_amd64.deb`)

## 에이전트 세션 복구

* [x] 앱 종료 전 에이전트 세션이 살아있던 워크스페이스로 이동하면 "에이전트 세션 복구" 다이얼로그가 뜬다\
  비고:
* [x] 다이얼로그에 세션별 provider 아이콘 + 이름 + 실행될 커맨드가 표시된다\
  비고:
* [ ] "모두 복구" 클릭 시 각 세션이 원래 탭의 쉘에서 resume 커맨드로 재개된다 (claude `--resume`, codex `resume`, opencode `--session` 등)\
  비고:
* [ ] resume 미지원 provider(cursor/copilot/aider/amp)나 provider 비활성 상태는 후보에서 제외된다\
  비고:
* [ ] 이미 에이전트가 실행 중인 탭은 복구 대상에서 건너뛴다\
  비고:
* [ ] "나중에"를 누르면 그 앱 실행 동안 해당 워크스페이스에서 다시 묻지 않는다\
  비고:
* [ ] detached 창에 있던 세션도 복구 다이얼로그에 포함되고 원래 탭에서 재개된다\
  비고:

## 세션 라이프사이클

* [ ] 앱 실행 중 에이전트 세션이 끝나면(정상 종료/프로세스 종료) 복구 후보에서 빠진다 — 재시작 후 묻지 않음\
  비고:
* [ ] 탭/pane/워크스페이스를 닫으면 그 세션은 복구 후보에서 제거된다\
  비고:
* [ ] 세션 복구 후 새 세션이 다시 라이브 세션으로 추적된다 (다음 종료 시 복구 후보에 반영)\
  비고:
* [ ] 앱 종료 시 실행 중이던 터미널/에이전트 프로세스가 같이 종료된다 (고아 프로세스 안 남음 — `ps`로 확인)\
  비고:
