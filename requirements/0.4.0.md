# Mahas 0.4.0 — 반영 요구사항 점검표

버전: `0.4.0` (`dist/mahas-0.4.0.AppImage`, `dist/mahas_0.4.0_amd64.deb`)

## 앱 이름 변경 (ade → mahas)

- [ ] 창 제목·빈 화면 로고·설정 화면 등 앱 곳곳의 표기가 `Mahas`로 보임  
  비고: 종료 확인 대화상자는 `Quit Mahas?`, 세션 복구 문구도 Mahas 기준
- [ ] 설치 패키지·실행 파일이 `mahas` — `which mahas`로 확인 가능  
  비고: 구버전 `ade` 패키지는 별개로 남아 있으므로 `sudo apt remove ade`로 제거
- [ ] 데스크톱 엔트리/앱 아이콘 표시 이름이 Mahas  
  비고: appId는 `com.mahas.app`

## 데이터 이전

- [ ] 첫 실행 후 기존 프로젝트·워크스페이스·북마크·설정이 그대로 보임  
  비고: `~/.config/ade` 디렉토리가 `~/.config/mahas`로 통째 이전됨 (state·아이콘 캐시·윈도우 위치 포함)
- [ ] 이전 후 `~/.config/ade`가 더 이상 존재하지 않음  
  비고: 디렉토리 rename 방식 — 복사본이 남지 않음
- [ ] `npm run dev`는 `~/.config/mahas-dev`를 쓰며 설치본과 격리 유지  
  비고: 기존 `ade-dev` 프로필이 있으면 마찬가지로 이전됨

## 에이전트 훅

- [ ] Settings → Agent hooks에서 이전에 설치했던 provider가 미설치로 표시됨  
  비고: 훅 마크가 `ade-hook` → `mahas-hook`으로 바뀌어 구 설치는 구버전으로 인식
- [ ] provider별 Install 클릭 시 정상 설치되고 이후 에이전트 이벤트(완료/입력 요청 알림)가 도착함  
  비고: 사용자 config 안의 구 `ade-hook` 엔트리는 재설치 시 자동 교체됨 — 이중 등록 안 됨
- [ ] `~/.grok/hooks/ade.json`, `~/.config/opencode/plugins/ade-events.js`가 앱 시작 시 정리됨  
  비고: mahas 소유 파일만 제거 — 사용자 작성 파일은 건드리지 않음
- [ ] 세션 복구·알림·탭 상태 점이 이전처럼 동작함  
  비고: 환경변수 계약이 MAHAS_*로 교체됨 — 같은 앱 안에서는 전부 일관 적용
