# ADE 0.1.2 — 반영 요구사항 점검표

버전: `0.1.2` (`dist/ade-0.1.2.AppImage`, `dist/ade_0.1.2_amd64.deb`)

## 앱 이름

- [ ] 설치된 앱/데스크탑 엔트리/작업 표시줄 표시 이름이 `ADE`로 표기됨  
  비고: 기존 상태(워크스페이스, 세션 기록)는 그대로 유지되어야 함 — 내부 데이터 디렉토리는 `~/.config/ade` 그대로
- [ ] 빈 화면 로고와 세션 복구 다이얼로그 문구가 `ADE`로 표기됨  
  비고:

## 알림

- [ ] 앱을 보고 있는 동안 다른 pane/tab에서 에이전트 이벤트가 오면 상단 중앙에 토스트가 내려옴  
  비고: OS 알림은 안 뜸 — 창이 포커스를 잃었을 때만 OS 배너
- [ ] 토스트 클릭 시 해당 이벤트가 발생한 workspace/pane/tab으로 이동하고 읽음 처리됨  
  비고:
- [ ] 여러 이벤트가 연달아 오면 토스트가 최대 4개까지 세로로 쌓임  
  비고: 오래된 것부터 잘려나감 — 알림 벨 목록에는 전부 남음
- [ ] 알림이 발생한 pane/tab을 직접 보고 있으면 배지/읽지 않음 표시가 즉시 사라짐  
  비고: 같은 디렉토리의 탭이 여러 개일 때도 해당 탭만 정확히 읽음 처리

## 세션 복구

- [ ] 같은 디렉토리에서 띄운 여러 codex/grok 세션이 각자의 탭으로 정확히 귀속됨  
  비고: 이전에는 첫 번째 매칭 탭에 몰렸음 — 재시작 후 Resume 다이얼로그의 세션 목록이 탭별로 맞는지 확인
- [ ] 복구 실행 시 같은 탭에 두 개 이상의 resume 명령이 입력되지 않음  
  비고: 한 탭당 하나의 세션만 복구
- [ ] 복구 순서가 pane 배치 순서 → pane 내 탭 순서를 따름  
  비고: pane당 가장 왼쪽 복구 탭이 활성화됨
