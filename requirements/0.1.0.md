# ADE 0.1.0 — 세션 반영 요구사항 점검표

버전: `0.1.0` (`dist/ade-0.1.0.AppImage`, `dist/ade_0.1.0_amd64.deb`)

## 알림 (attention-gated)

- [ ] 에이전트가 **입력 필요**(permission/prompt) → 알림 옴  
  비고:
- [ ] 에이전트 **정상 종료** / **에러** → 알림 옴  
  비고:
- [ ] Esc 취소, 서브세션 idle, 세션 시작/종료 등 → **알림 안 옴**  
  비고:
- [ ] 지금 보고 있는 탭에서 에이전트 완료 → OS 배너 없이 읽음으로만 기록 (알림 리스트에는 남음)  
  비고:
- [ ] 앱은 보고 있지만 **다른 탭/워크스페이스**에서 완료 → OS 배너 없이 워크스페이스 탭에 닷 + 벨 unread  
  비고:
- [ ] 창이 unfocused/minimized → OS 배너 + unread  
  비고:
- [ ] 보고 있는 탭에서 needs-input → 배너 없어도 unread 유지, 답한 뒤 다음 이벤트에서 읽음 처리  
  비고:
- [ ] 알림 클릭 → 해당 워크스페이스 + pane + 탭으로 점프 (detached 창이면 창 raise)  
  비고:
- [ ] 같은 이벤트/버스트 → 알림 합쳐짐 (연속 ping 없음)  
  비고:
- [ ] 훅 설치된 agent를 직접 종료 → "finished" 알림 안 옴 (process-exit 폴백 억제)  
  비고:
- [ ] 같은 디렉터리에서 에이전트 2개 → 각자 세션으로 정확히 귀속  
  비고:
- [ ] opencode: Esc 중단이 error가 아니라 cancelled로 처리  
  비고:
- [ ] claude: "waiting for your input"이 needs-input으로 옴  
  비고:
- [ ] Settings → agent hooks → Test: 앱 보고 있어도 OS 배너 항상 표시  
  비고:
- [ ] 로그 확인: `~/.config/ade/hook-raw.log` (raw payload), `notify-decisions.log` (판정 이유)  
  비고:

## 파일 변경 감지

- [ ] 외부(에이전트, git checkout 등)에서 파일 변경 → 열려있으면 조용히 리로드 + meta 라인에 "reloaded from disk" 잠시 표시  
  비고:
- [ ] atomic save(tmp+rename)하는 도구로 수정 → "deleted on disk" 배너 **안** 뜸  
  비고:
- [ ] 실제로 삭제된 clean 파일 → 배너 없이 meta 라인에 "deleted on disk"만, 저장하면 recreate 확인  
  비고:
- [ ] dirty 상태에서 외부 변경/삭제 → 배너 (Reload / Keep mine)  
  비고:
- [ ] 저장된 파일이 외부에서 바뀐 뒤 Ctrl+S → overwrite 확인
