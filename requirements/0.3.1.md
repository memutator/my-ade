# ADE 0.3.1 — 반영 요구사항 점검표

버전: `0.3.1` (`dist/ade-0.3.1.AppImage`, `dist/ade_0.3.1_amd64.deb`)

## 에이전트 목록

- [ ] 에이전트 목록 상단에 `이 워크스페이스 | 전체` 토글이 생김 — 사이드바 섹션과 에이전트 위젯 둘 다 표시  
  비고: 선택은 재시작 후에도 유지됨
- [ ] `전체` 선택 시 모든 워크스페이스의 에이전트가 `워크스페이스명 · 패널 N` 그룹으로 나열됨  
  비고: 다른 워크스페이스의 행을 클릭하면 그 워크스페이스로 전환된 뒤 해당 패널·탭으로 이동
- [ ] 작동 중인 세션 행에 경과 시간이 1초 단위로 표시됨 (`12s` → `1m 23s` → `1h 2m 3s`)  
  비고: 턴 시작 시점부터 카운트
- [ ] 턴이 끝난 세션 행에 마지막 완료 시점이 `5m 전` 형태로 표시됨  
  비고: 앱 재시작 후에도 남아 있음 (`3h 전` 등)

## 탭 상태 점

- [ ] 에이전트를 켤 때(연결/시작 배너 출력) 작동 중 초록 점이 뜨지 않음  
  비고: 실제 턴 출력이 0.9초 이상 지속될 때만 점등
- [ ] codex 등 hook이 없는 에이전트도 턴 종료 후 초록 점이 꺼짐 — 파일 워처 redraw로 다시 켜지지 않음  
  비고: 단발 redraw·프롬프트 echo·replayed 출력은 작동 중으로 오인하지 않음

## 터미널 링크

- [ ] 터미널에서 파일 경로 클릭 시 그 터미널이 속한 패널이 아닌 다른 패널에 에디터 탭이 열림  
  비고: file/web 탭을 이미 가진 패널 우선 — 탭 수 적은 쪽으로 분산
- [ ] 터미널에서 URL 클릭 시 같은 규칙으로 새 브라우저 탭이 열림 — 기존 웹 탭을 덮어쓰지 않음  
  비고: 터미널 패널 하나뿐이면 기존처럼 우측으로 분할되어 열림
