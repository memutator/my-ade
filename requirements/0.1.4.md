# ADE 0.1.4 — 반영 요구사항 점검표

버전: `0.1.4` (`dist/ade-0.1.4.AppImage`, `dist/ade_0.1.4_amd64.deb`)

## 세션 복구

- [ ] 이전 실행에서 살아남은(orphan) 에이전트 세션이 재시작 후 복구 제안에 뜸  
  비고: 이전에는 구버전 ADE에서 시작된 에이전트의 이벤트가 "외부 세션"으로 필터링돼 복구 제안이 비어 있었음 — 이벤트의 pane/tab 스탬프가 현재 탭과 일치하면 입양
- [ ] orphan 에이전트가 보내는 알림도 복원된 자기 탭에 정확히 귀속됨 (엉뚱한 탭/워크스페이스 배지 없음)
