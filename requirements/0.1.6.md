# ADE 0.1.6 — 반영 요구사항 점검표

버전: `0.1.6` (`dist/ade-0.1.6.AppImage`, `dist/ade_0.1.6_amd64.deb`)

## 세션 복구

- [ ] codex 내부 요약 스레드가 재개 제안에 뜨지 않음  
  비고: "catch-up 작성" 내부 스레드는 디스크에 세션으로 안 남아 `codex resume`이 "No saved session found"로 실패했음 — 이제 세션 등록 자체를 안 함 (실제 세션의 compaction은 계속 추적됨)

## 프로젝트

- [ ] `+` 워크스페이스 메뉴의 프로젝트 행에 휴지통 버튼이 있고, 두 번 클릭해야 삭제됨  
  비고: 첫 클릭이 버튼을 빨갛게 arm, 두 번째가 실행 — 메뉴가 닫히면 해제. 프로젝트의 모든 워크스페이스·todo·북마크·재개 기록이 함께 정리되고, 디스크의 디렉토리는 지우지 않음
- [ ] 활성 프로젝트를 삭제하면 다른 워크스페이스로 전환되고, 마지막 프로젝트 삭제 시 빈 화면(Empty State)이 뜸  
  비고: 이전에는 활성 워크스페이스 id가 댕글링할 수 있었음
- [ ] 삭제된 프로젝트의 워크스페이스에서 돌던 에이전트 프로세스도 함께 종료됨  
  비고: 탭 레코드 소멸 → pty kill 경로
