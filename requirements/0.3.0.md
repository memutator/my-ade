# ADE 0.3.0 — 반영 요구사항 점검표

버전: `0.3.0` (`dist/ade-0.3.0.AppImage`, `dist/ade_0.3.0_amd64.deb`)

## 사이드바 · 에이전트 목록

- [ ] 사이드바가 위(디렉토리 트리)/아래(에이전트 세션 목록)로 분할됨  
  비고: 가운데 경계를 드래그하면 비율 조절 — 재시작해도 유지
- [ ] 에이전트 섹션 헤더 클릭으로 접기/펼치기 — 헤더에 세션 수 배지 + 최악 상태 점 표시  
  비고: 입력 필요 > 오류 > 작동 중 > 읽지않음 순으로 집계
- [ ] 목록이 현재 워크스페이스의 패널별 에이전트 세션을 그룹으로 보여줌 — 행은 이름 + cwd 두 줄  
  비고: 세션 이름이 있으면 그 이름, 없으면 탭 제목/에이전트명
- [ ] 행 클릭 시 해당 패널·탭으로 이동 — 최소화 패널은 복원, detached 패널은 그 창이 포커스됨  
  비고: minimized/floating/detached 아이콘이 그룹 헤더에 표시됨

## 위젯

- [ ] 패널 탭 스트립 `+` → `위젯` → `에이전트`/`사용량` 2단 메뉴로 위젯 탭 생성  
  비고: 위젯 종류는 생성 시 고정 — 탭 안에서 전환하는 헤더는 없음
- [ ] 에이전트 위젯은 사이드바 에이전트 목록과 같은 뷰를 탭으로 보여줌  
  비고: 비활성 탭도 마운트 유지 — 탭 전환 시 내용이 겹쳐 보이지 않음
- [ ] 사용량 위젯에서 harness 선택 시 한도 대시보드 — claude/codex/gemini/copilot/zcode  
  비고: 각 CLI가 디스크에 남긴 자격증명으로 읽기 전용 엔드포인트 호출, 3분 자동 갱신 + 새로고침 버튼
- [ ] 자격증명 없음/미지원 provider는 사유를 표시 (지원 안 함 문구 포함)  
  비고: 선택한 provider는 탭에 저장되어 재시작 후에도 유지

## 패널 이름

- [ ] 패널 `⋯` 메뉴 → "패널 이름 바꾸기"로 이름 지정 — titlebar의 이름 pill을 더블클릭해도 됨  
  비고: 이름이 있으면 grip과 탭 스트립 사이에 pill로 상시 표시
- [ ] 이름 없는 패널은 생성 순서 번호(`패널 N`)로 표시 — split/이동해도 번호 유지  
  비고: 기존 저장 상태는 앱 시작 시 레이아웃 순서로 번호가 부여됨
- [ ] 패널 이름은 dock chip·분리된 창 제목·agents 목록 그룹 헤더에 반영됨  
  비고: 빈 이름으로 저장하면 이름 해제 — `패널 N`으로 복귀

## 탭 상태 점

- [ ] 터미널 탭의 닫기 슬롯이 상태등으로 동작 — 작동 중 초록 펄스 / 입력 필요 황색 / 오류 빨강 / 읽지않음 점  
  비고: 탭에 호버하면 점이 닫기 X로 바뀜 — 우선순위: 입력 필요 > 오류 > 작동 중 > 읽지않음
- [ ] 에이전트 턴 직후 화면 redraw 동안 작동 중 불이 깜빡이지 않음  
  비고: 출력 재개 직후의 짧은 유휴 구간을 무시

## 알림 · 세션

- [ ] 빠르게 연속된 완료 알림이 누락 없이 도착함  
  비고: 3초 버스트 병합이 같은 대상의 연속 ping을 삼키던 문제 수정
- [ ] 살아있는 에이전트가 있는 워크스페이스를 닫을 때 확인 경고가 뜸  
  비고: 세션 수와 함께 확인 — 취소 가능
- [ ] devin CLI의 stale 세션 락이 자동 정리되어 kill/크래시 후 session_locked로 안 막힘  
  비고: 살아있는 세션의 락은 절대 해제하지 않음 (flock + pid 검사)

## 동작 변경

- [ ] 보이는 패널이 하나뿐일 때 프로그래매틱 오픈(파일 열기 등)은 탭을 쌓지 않고 그 패널을 오른쪽으로 split  
  비고: 보던 내용을 덮지 않기 위함 — 패널이 2개 이상이면 기존처럼 포커스된 패널에 스택
- [ ] 패널 탭 스트립 첫 탭 앞의 여백이 절반으로 줄어듦  
  비고: 순수 스타일 변경

## 개발 실행 (dev 프로필에만 해당)

- [ ] `npm run dev`로 띄운 창은 타이틀바에 빨간 dev 배지가 표시됨  
  비고: dev 실행은 `appData/ade-dev` + `~/.config/ade-dev`로 격리 — 설치된 앱의 상태를 건드리지 않음
