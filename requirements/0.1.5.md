# ADE 0.1.5 — 반영 요구사항 점검표

버전: `0.1.5` (`dist/ade-0.1.5.AppImage`, `dist/ade_0.1.5_amd64.deb`)

## 알림

- [ ] opencode가 자동 승인되는 권한 요청("always" 규칙 등)에 대해 입력 필요 알림을 보내지 않음  
  비고: 이전에는 ~20ms 만에 자동 응답되는 요청도 needs-input으로 울렸음 — 800ms 유예 후 미해결 시에만 알림
- [ ] codex가 컨텍스트 자동 요약(compaction)할 때 알림이 오지 않음  
  비고: `{"recap":…}` 요약 턴은 실제 턴 종료가 아니라 중간 bookkeeping — 알림 없이 추적만

## 세션 복구

- [ ] 세션 복구 시 에이전트가 프로젝트 루트가 아니라 세션이 실제로 작동했던 디렉토리에서 재개됨  
  비고: `cd '<세션 cwd>' && <resume 명령>` 순서로 입력 — 하위 디렉토리 세션의 cwd 스코핑 문제도 차단

## UI

- [ ] 사이드바 루트 경로가 또렷하게 보임  
  비고: `--text-faint` → `--text-dim` + 11px
- [ ] 알림이 온 탭에 터미널 pane 내부 탭 스트립에도 점 표시가 뜸  
  비고: 이전에는 워크스페이스 탭에만 표시돼서 pane 안의 어느 탭인지 몰랐음
